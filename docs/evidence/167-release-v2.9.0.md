## 7. 已知取舍

1. **漂移系数 1/100 是保守值**：得分 0→100 只让 5 日中位落点偏移 ±0.5σ₅。极端行情下模型会偏钝，故同时给纯波动的 1σ/2σ 带供读者自行判断。
2. **情景概率是模型值**：正态 + 常数漂移，无事件窗口调整（FOMC / CPI 当日会低估尾部）。页面已标注「模型值，非保证」。
3. **关键位只取每侧最近 2 条**：更远的位（如 MA50 +10.9%）在 320px 下会把列表撑长，暂不展示。
4. **账户浮亏仍为 60 秒整刷新**（v2.8.0 遗留待决策项），未在本次改动范围内。
